# Change requests

Use for changes to Prov. locked or Locked items and shared interfaces. Open and Preferred items can be changed by the owning workstream with a one-line entry in the decision log.

## Format

- CR ID and date
- Originating workstream
- Current value or decision
- Proposed change
- Reason and evidence
- Affected CAD, electronics, firmware, costume or documentation
- Time and cost impact
- Decision: Approved / Rejected / Deferred
- Artifacts updated and revision numbers
